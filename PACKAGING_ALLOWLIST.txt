# PACKAGING_ALLOWLIST.txt · cio che e dichiarato spedibile
#
# Elenco IN POSITIVO. Un file di questa cartella che non compare qui viene
# RILEVATO dal build, che lo nomina con il suo percorso e diventa rosso, invece
# di ignorarlo in silenzio.
#
# CHI RILEVA E CHI IMPEDISCE, perche non sono la stessa cosa e per un ciclo
# intero questa intestazione ha promesso il contrario.
#
#   Il marketplace di questo plugin dichiara la sorgente su QUESTA cartella,
#   quindi l'installazione la copia per intero. Questo elenco non governa quel
#   percorso: rileva un file non dichiarato, non ne impedisce la copia.
#
#   Cio che IMPEDISCE e un hook git pre-commit, che sta a monte: un file non
#   dichiarato fa fallire il commit, e senza commit non c'e nessun install e
#   nessun update da cui possa uscire. Si arma una volta per repo con
#       python scripts/installa_hook_git.py
#   e il controllo C8 del cancello di confine diventa rosso se qualcuno lo
#   disarma. Dove si ferma anche lui: `git commit --no-verify` lo salta, misura
#   l'albero di lavoro e non l'indice, e un clone nuovo parte disarmato finche
#   non si lancia quel comando.
#
# Perche una allowlist e non una denylist: una denylist che dimentica una riga
# lascia uscire qualcosa e nessuno se ne accorge. Una allowlist che dimentica
# una riga fa mancare un pezzo di prodotto, e il build diventa rosso. Con in
# gioco l'identita di terzi si preferisce sempre il fallimento rumoroso.
#
# Formato: un pattern per riga, relativo alla radice del plugin (questa
# cartella). Righe vuote e righe che iniziano per cancelletto sono commenti.
# Le stelle valgono dentro un solo segmento di percorso: `skills/*/SKILL.md`
# non scavalca la barra. Un pattern cosi largo da coprire l'intero albero e
# rifiutato dal build: sarebbe una denylist scritta male.
#
# Le due direzioni dell'errore hanno due codici di uscita diversi:
#   2 = file presente nell'albero che nessun pattern dichiara
#   3 = pattern dichiarato qui che non trova piu nessun file
#
# Il controllore e `scripts/build_pacchetto.py` alla radice del progetto.
# =============================================================================
